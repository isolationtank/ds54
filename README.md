# Dunczen Scott DS54
> **Project Status:** Active / Open Source
> **Version:** DS54 (Commemorating John Lilly's 1954 NIMH Float Tank)

The **Dunczen Scott DS54** is the flagship isolation tank design of the **FOSITA** (Free Open Source Isolation Tank Association) initiative. This build is a tribute to Duncan Scott’s pioneering open-source tent work, reimagined as a unified, industrial-grade skeletal system.



## 🏗 Engineering Overview
The DS54 utilizes a "Layered Draping" construction method. By moving away from expensive T-slot aluminum, we achieve a saltwater-proof, high-thermal-efficiency environment for a fraction of the cost of commercial kits.

### Key Features:
* **Unified Skeleton:** A single-frame architecture using 2" Furniture-Grade PVC that supports both the water basin and the sloped enclosure.
* **Condensation-Clear Roof:** A specific 10% slope (45" front, 36" rear) ensures salt condensation rolls to the walls instead of dripping on the floater.
* **Maintenance-Lift Thermal Base:** Integrated 316 Stainless Steel levelers allow the entire 2,800 lb apparatus to be "jacked up" 2 inches to swap heating cassettes without draining the tank.

## 📂 The Layer Stack (Bottom to Top)
1. **Insulation Base:** 1" or 2" Rigid XPS Foam Board (40+ PSI).
2. **Heating Element:** Radiant Heating Film.
3. **The Load Spreader:** 1/2" Marine-Grade HDPE Sheet (The "Floating Floor").
4. **Protective Buffer:** Gorilla Pad / Felt Underlayment.
5. **Water Container:** 30 mil Vinyl Liner secured via PVC Snap Clamps (No-Drill).
6. **Thermal Skin:** Heavy-duty UV-resistant tarp or 6 mil greenhouse film.
